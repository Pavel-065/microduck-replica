# Microduck — самостоятельная сборка

**Русский** · [English](README.en.md) · [简体中文](README.zh-CN.md)

> Независимый проект по воспроизведению [Microduck от Pollen Robotics](https://pollen-robotics.com/microduck/).
> Сборочные чертежи, схемы с разнесёнными деталями и сборки для импорта в CAD, восстановленные по официальной модели MJCF.

Microduck — двуногий робот-утка высотой 25 см и массой 737 г. В нём установлено 15 сервоприводов Dynamixel XL330: 14 управляются моделью, обученной ходьбе с помощью обучения с подкреплением.

**Программное обеспечение открыто и распространяется по Apache-2.0. Аппаратная часть открыта частично:**

- ✅ **Плата RPI Robot HAT полностью опубликована:** [официальный репозиторий](https://github.com/pollen-robotics/elec_RPI_Robot_HAT), Apache-2.0. Доступны проект KiCad 9, Gerber, перечень компонентов, координаты монтажа и STEP. Самостоятельно восстанавливать эту плату не требуется.
- ❌ **Официальный проект платы `imu_to_dxl` не опубликован.** В этом репозитории представлена независимая реконструкция.
- ❌ **Официальных редактируемых CAD-моделей механики, полного перечня деталей и инструкции по сборке нет.**

> Исправление от 03.09.2026: ранее авторы утверждали, что аппаратная часть полностью закрыта. Это ошибка: они проверили основной репозиторий `microduck`, но пропустили аппаратные репозитории организации с префиксом `elec_`.

В `microduck_rl` опубликованы **полная модель MJCF и 47 STL-сеток**. MJCF содержит кинематическое дерево: соединения деталей, относительное положение с точностью до 0,1 мм, оси вращения, диапазоны движения, массы и тензоры инерции. **Этого достаточно, чтобы восстановить взаимное расположение деталей.** Результат представлен здесь.

> **О русской версии:** перевод главной страницы для [Pavel-065/microduck-replica](https://github.com/Pavel-065/microduck-replica) подготовлен по китайскому README [исходного проекта fanhao375](https://github.com/fanhao375/microduck-replica), коммит `6c37cd6`. Испытания, цены и даты относятся к исходному проекту. Вложенные документы и подписи на готовых изображениях пока сохраняют исходный язык. Авторство и лицензии сохранены.

### 💻 Программа: веб-панель управления 15 приводами

<p align="center"><a href="tools/servo-web/"><img src="assets/servo-web.png" alt="Веб-панель: ползунки, 3D-модель и проекция центра масс" width="720"></a></p>

Панель управляет приводами из браузера, отображает движение модели и проекцию центра масс, сохраняет позы, запускает последовательности, калибрует ноль, выгружает регистры и измеряет время обмена. Используется при сборке и стендовых проверках.

Серверная часть не зависит от SDK Feetech: [`feetech.py`](tools/servo-web/feetech.py) непосредственно обменивается пакетами по руководству протокола 2026 года. Есть симулятор приводов на уровне протокола для проверки калибровки, изменения ID и записи регистров без оборудования.

`FeetechIo` для официальной программы управления уже написан через `RobotIo` с протоколом v1 из rustypot и обновлён под официальную версию 0.14.1. Загрузка на плату ожидает калибровки нулей. Код — в [ветке `feetech`](https://github.com/fanhao375/microduck/tree/feetech).

[Веб-панель](tools/servo-web/) · [Архитектура адаптации](software/飞特适配架构.md) · [FeetechIo](https://github.com/fanhao375/microduck/tree/feetech) · [Протокол и регистры Feetech](docs/飞特资料/)

### 🧠 Алгоритмы: обучение ходьбе ещё не начато

В официальном [microduck_rl](https://github.com/apirrone/microduck_rl) модель обучают в MuJoCo, экспортируют в ONNX и запускают с частотой 50 Гц. Для Feetech сначала нужно откалибровать **нулевые положения и направления суставов**. Работа находится на этом этапе.

У HD-1910 отличаются момент, передаточное отношение и демпфирование, поэтому готовую модель, вероятно, придётся переобучить. Постоянная момента, предел скорости, PID, трение и другие необходимые параметры собраны в [перечне данных перед обучением](docs/HD-1910训练前数据清单.md). Измеренные значения отмечены, недостающие вынесены в задачи.

## Структура сборки

К корпусу массой **199 г** крепятся две ноги и шея с головой.

| Цепь | Узлы по порядку от корпуса |
|---|---|
| Левая нога | Переход `hip_yaw` → `hip_roll`: 23 г → узел `hip_roll`: 6 г → бедро: 48 г → голень: 22 г → голеностоп и стопа: 30 г |
| Шея и голова | Основание шеи: 37 г → наклон шеи: 6 г → поворот и боковой наклон головы: 49 г → голова с клювом: 189 г |
| Правая нога | Переход `hip_yaw` → `hip_roll`: 23 г → узел `hip_roll`: 6 г → бедро: 48 г → голень: 22 г → голеностоп и стопа: 30 г |

**Полная масса: 737,2 г. Габариты: 144 × 141 × 264 мм.** Массы отдельных узлов округлены.

Корпус и голова весят почти одинаково: 199 и 189 г. На голову приходится четверть массы робота, центр масс расположен высоко — это усложняет обучение ходьбе.

## Суставы

У каждой ноги 5 степеней свободы, у головы и шеи ещё 4: **14 суставов под управлением модели**. Пятнадцатый XL330 двигает клюв через рычажную связь и не входит в пространство действий модели.

| Сустав | Диапазон |
|---|---|
| `hip_yaw` | −25° … +30° |
| `hip_roll` | ±22° |
| `hip_pitch` / `knee` / `ankle` / `head_pitch` | ±90° |
| `neck_pitch` | −90° … +60° |
| `head_yaw` | ±170° |
| `head_roll` | ±25° |

## 📋 Перечень компонентов — BOM

**Что купить и в каком количестве:** [BOM](BOM.md), [английская версия](BOM.en.md).

15 приводов, 14 подшипников, примерно 325 крепёжных элементов и 2 платы для изготовления. Количество подсчитано по ссылкам на геометрию в MJCF: 38 типов сеток / 75 экземпляров. Есть компоненты плат и артикулы LCSC.

## Сборки для CAD

В `cad/` расположены STL **с уже применёнными преобразованиями в мировую систему координат**: после импорта детали занимают свои места. Исходные 47 STL используют локальные координаты, поэтому при прямом импорте накладываются друг на друга в начале координат.

- `00_Microduck_整机装配体.stl` — робот одним файлом, 796 792 треугольника.
- `01`–`15` — 15 узлов, сгруппированных по твёрдым телам.
- `零件对照表.json` — соответствие узлов исходным сеткам.

Единицы — миллиметры. Подходят FreeCAD, Fusion 360, SolidWorks, Blender и слайсеры.

### Редактируемые параметрические модели

STL в `cad/` и `print/` можно печатать, просматривать и измерять, но они не содержат истории построения параметрической модели.

В [fanhao375/microduck-replica-cad](https://github.com/fanhao375/microduck-replica-cad) доступны **16 сборок и 40 деталей SolidWorks**, а также **21-страничное руководство** с иллюстрациями. **Архивы находятся в Releases**, а не в основном списке файлов.

Автор — [机械行者Robo](https://github.com/fanhao375/microduck-replica-cad#图纸作者机械行者Robo). Эти исходники нужны для изменения размеров, толщины стенок и выпуска чертежей.

| Компонент | Характеристики |
|---|---|
| **Основная плата** | **Radxa Zero 3W**, серийный покупной модуль |
| SoC и память | RK3566, 4 × Cortex-A55, Mali-G52, NPU 0,8 TOPS. Официально 1 ГБ ОЗУ / 32 ГБ eMMC; для сборки предлагается 2 ГБ / 16 ГБ, [обоснование](docs/电控采购清单.md) |
| **Шина приводов** | Однопроводная полудуплексная TTL, не RS-232 и не RS-485. Dynamixel Protocol V2, 1 Мбит/с, `/dev/ttyS2` |
| **`imu_to_dxl` v2** | LSM6DSV16X с интерфейсом Dynamixel. Официальный протокол: ID 200, регистр 124, блок 12 байт, общий `sync_read` с приводами. Прошивка Feetech 0.2.0 использует другие параметры, см. обновление выше |
| **RPI Robot HAT** | TLV320AIC3104 `0x18`, неиспользуемый BMI088, Stemma для ToF. [Открытый проект](https://github.com/pollen-robotics/elec_RPI_Robot_HAT) |

| Датчики | IMU LSM6DSV16X; ToF VL53L5CX/L8CX, 8 × 8; IMX219 / Raspberry Pi Camera v2 |

Для основной платы IMU представлена устройством Dynamixel, поэтому ориентация и состояния суставов приходят в одной транзакции. Отдельная I²C к основной плате и программное объединение измерений не требуются: блок SFLP в LSM6DSV16X выдаёт игровой кватернион ориентации и оценивает смещение нуля гироскопа.

## Можно ли собрать робота

Исходный проект считает конструкцию воспроизводимой. Его сводка:

| Что требуется | Что доступно |
|---|---|
| Геометрия | ✅ 47 STL |
| Взаимное расположение | ✅ Точность до 0,1 мм, подготовленные изображения |
| Оси и диапазоны | ✅ Все 14 суставов |
| Массы и инерция | ✅ 15 твёрдых тел |
| Приводы | ✅ XL330 ×15, [сравнение](docs/执行器选型.md) |
| Подшипники | ✅ Ø22 × 16 × 4 и Ø15 × 10 × 3 мм |
| HAT | ✅ [Официальные KiCad, Gerber и BOM](https://github.com/pollen-robotics/elec_RPI_Robot_HAT) |
| `imu_to_dxl` | ⚠️ Официальный проект закрыт; протокол и регистры восстановлены. Собственная плата и прошивка развиваются здесь |
| Основная плата | ✅ Покупная Radxa Zero 3W; первоначальное предположение о специальной плате было ошибочным |
| Крепёж | ✅ [Восстановлен по отверстиям STL](docs/紧固件反推.md) |
| Аккумулятор и датчики | ✅ NP-F550 2S, IMX219, VL53L8CX, LSM6DSV16X |
| Прокладка проводов | ❌ Готовой схемы нет |
| Программа управления | ✅ Официальный код Apache-2.0 рассчитан на Radxa Zero 3W; замена платы потребует переноса |
| ONNX-модели | ✅ В исходном проекте указаны 9 моделей для штатной конфигурации; изменение оборудования может потребовать переобучения |

**STL для симуляции не гарантируют пригодности к изготовлению:** могут отсутствовать нужные допуски, резьбы, места термовставок и проходы для проводов. При прямой печати возможны инженерные доработки.

**Самостоятельная сборка может оказаться дороже готового робота.** Исторические цены из документации на 15 XL330: около 359 долларов в международном ROBOTIS, 412 долларов в американском и 603–629 евро с налогом в Европе. Дополнительно нужны основная плата, аккумулятор, две PCB и пластик. Это цены исходного проекта, а не текущие проверенные предложения. [Расчёт](BOM.md).

## Практический путь

**Использовать восстановленную механику и самостоятельно собрать электронику.** Для оригинального варианта:

| Часть | Решение |
|---|---|
| Механика | STL и схемы этого репозитория |
| Приводы | 15 XL330 |
| Основная плата | Radxa Zero 3W, как в оригинале |
| IMU | `imu_to_dxl`: LSM6DSV16X + микроконтроллер + полудуплексный приёмопередатчик |
| HAT | Четырёхслойная плата по официальным Gerber. Без записи звука её можно исключить, но потребуется отдельный адаптер с управлением направлением полудуплексного обмена. [Подробнее](docs/电控采购清单.md#六两块-pcb) |
| Программа | Официальная программа на Rust, Apache-2.0, для штатной основной платы |
| Модели управления | Официальные ONNX для штатной конфигурации; при изменениях — обучение через [microduck_rl](https://github.com/pollen-robotics/microduck_rl) |

Авторы пересмотрели первоначальный вывод: **робота можно воспроизвести целиком**, поскольку основная плата серийная, а функции и протокол специальных плат восстановлены по коду. [Исследование](docs/硬件方案逆向.md).

## Три проблемы при настройке

1. **UART2 занят консолью входа Armbian:** службу `serial-getty@ttyS2` нужно отключить через `systemctl mask`. Занятый порт обнаружили командой `fuser -v /dev/ttyS2`.
2. **I2C3 конфликтует с FUSB302:** аппаратная I²C на контактах 3/5 лишает USB-C согласования PD; обычное питание 5 В остаётся доступным.
3. **NPU отключён по умолчанию:** для моделей RKNN требуется установить соответствующий overlay и перезагрузить плату.

## Повторное создание материалов

```bash
# 1. Загрузить исходные репозитории; исключение для печатных деталей описано в NOTICE.md.
bash scripts/fetch_upstream.sh

# 2. Создать сборочные изображения.
python scripts/render_assembly.py upstream/microduck_rl assembly-drawings

# 3. Экспортировать сборки STL.
python scripts/export_assembly_stl.py upstream/microduck_rl cad

# 4. Повторить анализ отверстий.
python scripts/analyze_holes.py upstream/microduck_rl/src/mjlab_microduck/robot/microduck/assets
```

Зависимости: `mujoco`, `numpy`, `pillow`, `scipy`. Для рендеринга нужен контекст OpenGL.
