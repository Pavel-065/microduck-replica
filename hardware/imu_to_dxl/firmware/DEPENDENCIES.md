## Запуск сборки

Можно редактировать исходники в VS Code и выполнить в терминале PowerShell каталога прошивки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\build.ps1 -ToolchainRoot 'E:\Keil_v5\ARM\ARMCLANG'
```

Заменить путь из примера каталогом своей установки Arm Compiler. Конфигурация задач VS Code в репозиторий не включена.
Сборка заменяет прошивку в `Build`; если используется только веб-страница ориентации, следует сохранить поставляемый `Build/imu_to_dxl.hex`, пересборка не нужна.
В репозитории хранится только этот предварительно собранный HEX; `.bin/.map/.axf`, журналы сборки и результаты тестов остаются локальными и исключаются через `.gitignore`.

В Keil можно открыть `MDK-ARM/imu_to_dxl_jlink.uvprojx` (J-Link) или `imu_to_dxl.uvprojx` (ST-LINK); при первом использовании проверить компилятор, пакет устройства, отладчик и алгоритм записи. Скрипт J-Link устанавливает проверенную скорость SWD 100kHz. Сборка создаёт `.axf/.hex/.bin/.map`; CLI-скрипт дополнительно создаёт журнал сборки и список SHA-256 результатов.

Оба способа используют Cortex-M0+, C11, `-Oz`, программную плавающую точку, короткие enum, MicroLIB, `STM32G031xx` и `HSE_VALUE=16000000`.
Разметка линковки: Flash `0x08000000..0x0800FFFF`, RAM данных `0x20000000..0x200017FF`, последние 2KiB `0x20001800..0x20001FFF` отведены стеку, начальный SP `0x20002000`. Размер стека нужно менять одновременно в стартовом файле и scatter-файле.

Наблюдатели SWD / J-Link в `tools/servo-web` декодируют из HEX образ 10,724 байт (0.2.0) и используют SHA-256
`66bc7c532f5a1ad87e3dfff71a4b51f8c4f20840a8f62436874fa5b7c665938e`
для привязки проверенных `sample=0x2000006C` (60 байт) и `tick=0x20000A34` (4 байта), без необходимости включать MAP в репозиторий.
После пересборки нужно проверить символы и их размеры по локальному MAP, проверить хеш нового образа и лишь затем обновлять наблюдатель.

<a id="主机测试与文件完整性"></a>
## Тесты на компьютере и целостность файлов

Для C-тестов на компьютере нужен MSVC; сначала запустить **x64 Native Tools Command Prompt / Developer PowerShell**, затем выполнить `Tools/test.ps1 -PythonExe '自己的Python路径'` (указать путь к своему Python). Тестовый скрипт не устанавливает программы и не подключается к оборудованию.

`Drivers/CMSIS/dependency-hashes.json` содержит SHA-256 включённых файлов драйверов; метаданные исходного commit ST находятся в `Drivers/CMSIS/Device/ST/STM32G0xx/source-commit.json`. Область проверки сборки и реальной платы описана в [VALIDATION.md](VALIDATION.md).
